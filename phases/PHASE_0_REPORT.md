## Tests

Phase 0 ships no test suite; `tests/` was cleared so that subsequent
phases write fresh tests against the new package layout. The brief
moves coverage to Phase 7.

In place of `pytest`, the Phase 0 gates are `make lint` and the
`pre-commit` hook run:

```
$ ruff check .
All checks passed!

$ ruff format --check .
1 file already formatted

$ pre-commit run --all-files
trim trailing whitespace.................................................Passed
fix end of files.........................................................Passed
check yaml...............................................................Passed
check toml...............................................................Passed
check for merge conflicts................................................Passed
check for added large files..............................................Passed
ruff.................................................(no files to check)Skipped
ruff-format..........................................(no files to check)Skipped
nbstripout...........................................(no files to check)Skipped
```

The "no files to check" skips are because the only Python file in the
tree at end of Phase 0 is `src/audio_priors/__init__.py`, which the
in-line `ruff check .` (run from the repo root) already validated.

## Known issues

- `numpy` upper bound relaxed from `<2.1` to no upper bound. The local
  Python 3.13 venv has no `numpy<2.1` cp313 wheel, and the source build
  fails on Apple Clang. Brief Section 3 allows this under "verify
  latest compatible versions at execution time". Reintroduce a ceiling
  in Phase 8 if needed for the 3.10/3.11/3.12 matrix.
- Legacy commits in history carry AI-tool trailers in their bodies.
  Brief Section 2.2 forbids such trailers in commit messages. Phase 10
  schedules the `git filter-repo` pass that will strip them alongside
  any wrong-author rewrite. Phase 0 leaves history untouched.
- Working tree is at `/Users/dhruvsood/SongAddiction`. Only the GitHub
  remote was renamed to `audio-priors`. Local directory rename is
  cosmetic and deferred.
